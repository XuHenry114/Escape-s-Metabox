# Escape's Metabox — 嵌套盒子推箱子（网页版）

根据洛谷题解文章《爆肝万余字！2026 年洛谷愚人节比赛 O 题 T722404 Escape's Metabox 题解》制作的
浏览器端推箱子游戏。玩家操控 `AC`，从 1 号盒子出发，穿过嵌套盒子，最终到达 50 号盒子（出口）。

## 游戏机制（与原文一致）

- **WASD / 方向键** 移动；空格或 E = 进入/退出（interact）；Z 撤销；R 重置；H 帮助。
- **推动**：只能推不能拉；优先推动，推不动时尝试进入。
- **进入**：盒子无法推、且对应方向边缘正中非墙时，缩小进入盒子，视角放大进入该盒子的内部空间。
  进入落点 = 该方向边缘正中格（右进→#22、左进→#28、上进→#46、下进→#4；每空间 AC 卡即该落点）。
- **退出**：站在内部空间开放边缘格、向着中心外移动即可退出（题解"从 #15(3,1) 退出"证明任意边缘格均可）。
  盒子也可以被推出空间（推到空间边缘再推一格 → 盒落到父空间同向邻格）。
- **盒子类型**：
  - `0B`：正常盒子，可推可进出。
  - `1.00MB`（1MB）：单向盒，进入会转移到同编号的 0B 盒（全图查找，含未访问空间基础布局）。
  - `999.00MB`（999MB）：墙，不可推不可走。
  - `MLE`：稳定，共用同一个空间的普通盒（同编号盒子共享空间）。
  - `TLE`：刷新盒，每次进入开辟一层新空间，直接退出恢复初始状态。
  - `UKE`：末影盒，共用空间，直接进入会把所在盒子的空间信息改为 0B（标记，并与既有同名 0B 交换）。
- **递归嵌套**：盒子内可含同号盒子（如 5ms 内含 5ms、8ms 内含 8ms/0B）→ 循环嵌套，视角递归放大；
- **穿梭（同尺寸盒互穿）**：退出落点直面同尺寸盒时直接进入，落点 = 退出格沿方向轴的**镜像格**
  （a/d → (r, 8−c)，w/s → (8−r, c)）——即题解注「同等大小的盒子可以从对应位置穿梭」
  （普通进入仍只能落边缘正中 #4/#22/#28/#46；非正中进入须借助穿梭）。
- **目标**：从 1ms 进入 2、3、… 直到进入 50ms（出口）即通关。

## 运行

```
双击 index.html（file:// 亦可，UI 自动降级：引擎→levels.data.js→fetch→占位数据）
或：启动游戏.bat（本地服务器 + 自动打开）
或：npx serve . / python -m http.server 8000
```

主要文件：
- `index.html` — 游戏界面（单文件，内嵌 CSS/JS；依赖 `src/engine.js` 的 `window.NetsGame`）
- `src/engine.js` — 游戏引擎（嵌套空间/进出/推动/1MB 转移/TLE/UKE/视角栈）
- `src/levels.data.js` — 关卡数据（`data/box-*.json` 构建产物；`window.LEVELS_DATA`/`EGG_DATA`）
- `data/box-01..50.json` — 50 个盒子结构数据（题解 57 张结构地图转录；已全量复核）
- `data/box-egg1..4.json` — 4 个悖论彩蛋
- `src/replay.js` — 题解完整通关码回放验证器（`node src/replay.js`，`--selftest` 71 断言）
- `src/validate-data.js` / `src/build-data.js` — 数据校验与构建
- `dev/` — 测试与调试脚本（integration-smoke / ui-e2e 五场景 95+ 断言 / segment-wise / ui-contract…）
- `spec/` — 规范文档（数据格式 / 引擎规则 / 完整通关码 solution.txt）

## 数据来源与验证

- 数据由题解中 57 张「结构地图」截图（每个编号盒子的 7×7 内部结构）转录，54 个 JSON 文件全部通过
  `src/validate-data.js` 机器校验；1-50 号盒经两轮全量人工复核（`dev/recheck-*.md`），
  修正了 box-10 #32（曾误录为 WA，实际为 MLE 墙）。
- `node src/replay.js` 用题解附录《完整通关代码》回放验证引擎机制（**已通过段标 1-25 全 ✓ + 27/28/29 ✓ + 30/31/32 ✓**；
  段标 26 = 题解叙事位早于到达（26-进入在其后 token 内，见 `dev/seg26-spec.md` §3.5）；33-50 为持续校准带
  （唯一断点 = 段 33：31 层 (3,2) B1 门栓结构性死锁，33 盒 (6,4)/(6,6) 机械可达性已验证但路径被锁，
  记录见 `dev/seg33-50-spec.md`）；`--selftest` 71 断言全过；段标判定为「首次到达」事件语义
  （visited，以 spaceId 为准））。
  引擎稳定版备份：`src/engine-v2-mirror.js`（= src/engine.js；定版前版本：`src/engine-v2.1.0-pre-twinfix.js`）。
- 玩家可从头游玩：进入 1ms → 2ms → … 依题解路径逐步推进（每关地图与题解原文一致）。
