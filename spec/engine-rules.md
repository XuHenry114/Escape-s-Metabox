# Escape's Metabox — 引擎规则规范（v1）

引擎实现为纯 JS（无 DOM），供 UI 层调用，并另附 Node 回放验证脚本。

## 数据模型

- `SPACES`：`{ [n]: {type: 'MLE'|'TLE'|'UKE', base: [49 cells]} }`，n=1..50，cells[i] 为卡 i+1
  - cell 字段：`label`（MLE/TLE/UKE/WA/AC）、`space`（0..50）、`size`（'0B'|'1.00MB'|'999.00MB'）。
- 运行期把每个非墙、非 WA/AC 的格子视为一个 **盒实例**：
  `{ uid, spaceId, type: '0B'|'1MB', pos: {r,c}, spaceType: label }`
  （label 就是该实例所属编号空间自身的类型 MLE/TLE/UKE，由数据冗余保存。）
- WA/AC 格 = 空地；`size==='999.00MB'` = 墙。
- 一个空间实例 = 7×7 网格，格子上可以有：墙 / 空地 / 盒实例 / 玩家。
- 空间状态：
  - 每编号空间有 **1 个共享实例**（MLE/UKE 共用该实例；由 `type` 决定）。
  - TLE 空间：从 box 进入时**创建新层**（初始布局的深拷贝，包含该格上的盒实例）；玩家**直接退出**该 TLE 盒时销毁该层并恢复盒实例为初始布局（下次再进又是全新一层）。

## 玩家状态

- `viewStack`: 视角栈。最底层是根（1 号空间），之后每层是一条记录 `{boxUid, spaceId(进入后所在空间), pos}`。
- 简化表示：`(spaceInstance, pos, parentContext)`；parentContext = `{spaceInstance, boxUid, boxPos}`（当前盒实例在其父空间中的位置）。
- 玩家所在格永远是可走格（空地）。

## 移动（w=上 a=左 s=下 d=右）

走向目标格 t：

1. t 是空地 → 走。
2. t 是盒子 C → **尝试推动**（优先级：推动大于进入）：
   - 沿移动方向找连续盒子链（C 之后仍是盒子则并入链），链末格之后：
     - 是空地（或越界=推动失败）→ 整个链平移一格，玩家走入 C 原位置。
     - 是墙/越界且不可推 → 进入判定。
3. **进入判定**（推动失败时自动发生）——修缮版（用户定版）：
   - 从链中最远（相对玩家）开始到最近，找第一个 **合法** 盒子：
     - 合法 = 该盒 `type==='0B'|'1MB'` 且 **其所属空间实例的对应边缘正中格非墙**（"对应方向边缘正中间有空隙"）。
   - **最远的合法盒子会被其前面的一个项目进入**：
     - 其前面项目是 AC → AC 进入（照旧）；其前面项目是盒子 → 该盒按 AC 相同方式进入（嵌套进入盒）。
     - 其余项目（未进入的盒 / AC）正常向推动方向前进一格。
   - 命中合法盒 B(k)：
     - 若 `B.type === '0B'`：进入 → 玩家视角进入 B 的空间实例（MLE/UKE 共用实例；TLE 新建层），落点 = **方向对应边缘正中格**（#4/#22/#28/#46）。
     - 若 `B.type === '1MB'`：**转移** → 找编号 B.spaceId 的 **0B 盒实例**（type='0B' 且 spaceId 相同；若多个，优先当前空间中→全图唯一性校验），进入其空间实例，落点 = 同一方向对应边缘正中格。
     - UKE 特例：进入的若是 UKE 型空间对应的 1MB/0B 盒实例：该实例 type 改为 '0B'；若此前已有同名 0B 实例，将其改为 '1MB'（交换标记）。
   - **进入失败且链末越界** → **推出**（修缮版）：链末盒被推出当前空间（落入父空间同向邻格），其余项目（含 AC 与未推出的盒）正常向推动方向前进一格。推出仅当父空间同向邻格为空地。
4. 记录事件（供 UI 动画/音效）：walk / push / enter / teleport / blocked / mark / win。

## 退出

- 玩家处于盒内部空间，站在**任意开放边缘格**（行1/7或列1/7，格为地）并向远离中心移动：
  - 父空间中盒实例的相邻格（boxPos + dir）：
    - 空地 → 退出，玩家落于此格；视图回到父空间（当前盒实例保持原位）。
    - 盒子 → 尝试推动：链（含该盒）末为地 → 推开，玩家退出落到该格；链末为墙/不可推 →
      - 若该盒与"所在盒"同样大小（同为 0B 或同为 1MB）→ **穿梭**：玩家进入该盒，落点 = 方向对应边缘正中（镜像位置）。
      - 否则 blocked（不移动）。
    - 墙 → blocked。
- **推出（修缮版）**：AC 向边缘有开口的位置推动一个或数个盒子，最远的项目会被推出（按 AC 相同方式），其余项目（包括 AC 和没有推出的盒子）正常向推动方向前进一格。
- **穿梭（修缮版）**：退出点的盒子无法推动时，同等大小的两个盒子可以从对应位置穿梭；AC 推动一个或数个盒子时，最远的项目会进行穿梭（按 AC 相同方式），其余项目（包括 AC 和没有推出的盒子）正常向推动方向前进一格。
- 直接退出 TLE 空间：销毁该层，恢复 TLE 盒实例自身布局为初始状态（附带的父空间中该 TLE 盒指向新层）。
- UKE "标记"（见上）：1MB→0B 交换记录事件 `mark`。

## 胜负

- 起点：1 号空间，玩家位于 1ms 的 AC 卡所在格。
- 胜利：进入 50 号空间（50 号盒）→ `win` 事件（显示通关画面；50ms 内部为自由区，见 50ms 地图）。

## 快捷调试 API（UI 用）

- `init(data)`、`reset()`、`move(dir)`、`undo()`、`getState()`（返回视图空间 + 玩家位置 + 当前盒编号栈 + 移动计数 + events 队列）、
  `jump(spaceId)`（直接跳到某空间，调试/跳关用）。
- **注意（修缮版）：进入/退出/穿梭仅通过移动（wasd/方向键）自动完成，`interact()`（空格/E）入口已删除。**
- 移动计数：可行移动（含 push）计数；blocked 不计数。
